# Story Garden: a little collection, entirely yours

本次为已有 Story Garden 增加四处轻提示，沿用 mutu-behavioral-ux。代码通过 `feat/story-garden` 分支与 PR #1 审阅，未修改 Supabase，尚未合并到正式版。

## 已实现

- My notebook 新增个人故事集封面：matcha / cream / lilac 三色，leaf / flower / sprout 三种植物印章，可选最长 60 字符的私人笔名。点击 Save my cover 后保存至当前账号、当前社区，跨设备读取。封面笔名不是公开文章署名，也不会改变匿名文章。
- 作者阅读自己的文章时，真实 received_reactions 非空才出现压花。点击展开：Your words stayed with someone. 仅作者看到真实、去重的读者人数，不返回回应者身份。一个人同时选两种回应仍只算一位；撤回、双向拉黑、故事隐藏作者与资格失效会更新统计。旧版接口尚无人数时只显示已有真实回应类型。
- 发布成功后显示保存的标题和实际共享身份，匿名仍显示 A community member。文案：There’s a little more you in the garden now. 保存失败不出现完成页面。
- 他人真实文章正文后增加静态纸签：There’s a version of this only you can tell. Begin my own page 从空白开始，保留未发送回复的离开提醒。

示例文章没有伪造压花、读者人数或发布成绩。没有公开排行、热度、计时弹窗、推送、首次成就认证或增长埋点。静态封面人人可用，不以发表篇数解锁装饰。压花只描述实际回应，不把回应推断为已验证的情绪改善。

## 手动升级

1. 已安装原来的 migration-story-garden.sql 后，运行 scripts/migration-story-garden-notebook.sql。
2. 运行 scripts/verify-story-garden-notebook.sql。结果预期写在脚本内。
3. 部署本次前端并沿用已有 mutu_stories 浏览器开关。

升级增加 story_notebooks 一张私有表、两个经过社区资格检查的 RPC，并更新既有 story_private.project 的作者专属字段。没有修改既有安装脚本；如果以后重跑旧安装脚本，必须再运行本次升级脚本恢复作者人数投影。

升级脚本可重复运行。封面更新采用版本检查，旧版本不能覆盖新版本。没有公开表权限，没有客户端可传入的 owner ID，没有新社区权限。SQL 仅在独立 PGlite 测试数据库中执行。

尚未升级时，真实故事和手记仍可阅读；封面显示默认外观，设置加载失败明确提示，不假装保存成功。封面编辑失败保留输入；离开时可保存后离开、继续编辑或放弃改动。冲突时原输入保留，可复制笔名后放弃本地改动并重新打开读取最新设置。

## 验证与验收

故事模块 54 项测试通过，覆盖后端隐私与生命周期、客户端和界面行为。生产构建通过。浏览器访问本地预览遇到 ERR_BLOCKED_BY_CLIENT，未完成窄屏视觉或真机验收。

人工验收：两账号分别保存不同封面并刷新；匿名发布不展示封面笔名；第二账号对文章选两种回应，作者只看到一位读者，第二账号看不到人数；取消两种回应后压花消失；保存期间断网与离开保护；320px/390px 下长笔名、键盘和按钮换行；减少动态效果设置。

## UX 设计核对

任务与障碍：希望自己的表达值得被珍藏，同时担心不够成熟、不够成功。七种动机已审阅，选择 Pride（真实认可）、Ownership（自己的故事集）、Agency（自选呈现且可退出）。

流程与层级：阅读 → 自愿从空白写作 → 真实保存 → 署名纸页 → 回到私人手记；收到真实回应后可展开压花。手记先封面，再收起的外观设置，再本人文章与收藏。无需配置即可使用，正文和原有写作承诺不变。

视觉：奶白、抹茶、淡金，少量淡紫封面；纸张书脊与植物线稿。发布纸页短动画和手动展开压花动画均遵守 prefers-reduced-motion，没有持续动画或按活跃度枯萎的植物。

状态：加载重新核验资格；设置故障不阻断文章；失败无成功提示；空手记仍有完整封面；完成后允许安静离开。草稿、匿名、社区资格、回复意愿、屏蔽、默认关闭的功能开关和真实匹配逻辑不变。

成功指标建议通过自愿反馈与可授权的后续研究观察：作者是否更愿意保留自己的表达、再次写作，真实回应是否帮助自愿交流；不以公开人气或浏览时长衡量。本次不新增分析追踪，也不把故事或回应算作已验证交换或 Token。
