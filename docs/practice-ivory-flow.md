# Practice Together: ivory flow

## Goal and hierarchy
Help a member find a reciprocal practice partner, arrange a session in the
existing Messages thread, practise, and give useful feedback. The previous
discovery screen had repeated headings and competing shortcuts before the
partner list. This revision uses ease, agency and visual warmth: compact
preferences, one discovery heading, existing My Sessions navigation, and
progress and instructions below discovery.

## Surfaces
- Discovery: reduced heading weight, location chip on the pixel scene, existing
  garden/list bypass and anonymous partner encounter dialog.
- Preferences: dedicated native dialog with a bounded scroll area, close and
  Escape handling, focus restoration and preserved drafts. Existing type/time
  editors and capability-gated starting experience remain connected.
- Setup: distinct want/help cards; optional fields keep their existing behaviour.
- Invitations and sessions: ivory cards, consistent typography and touch targets.
- Platform Messages: restyled existing scheduling, meeting link and time-change
  components, with existing validation and partner confirmation.
- Guide: round progress, existing resumable stages, optional preparation details,
  existing timer rather than a hardcoded concept duration.
- Feedback: observed strengths and private suggestions in distinct surfaces;
  original review-before-submit and consent rules remain authoritative.
- Progress: My progress title, framed evidence and existing private recommendations.

## Trust and states
No sample profiles, counts, dates or endorsements are persisted. Existing error,
empty, loading, disabled, pending, completed and disputed states remain. Actual
sharing remains controlled by the recipient, rather than the concept's proposed
reviewer checkbox. No automatic verification, SQL changes or rollout changes.
The suggested planning survey in the concept is represented by existing teammate
traits, not a new unsupported backend field. Private case-upload storage is not
introduced by this visual update. Avatar choices and existing pixel scenes stay.

The engagement loop remains relevant partner -> mutual invitation -> scheduled
practice -> two confirmations -> verified exchange -> next useful practice.
Measure invitation acceptance, scheduled sessions and verified exchanges, not
time in the garden. Styling respects reduced motion and visible keyboard focus.

## Validation boundary
Run affected component tests and production build. Native dialog behaviour and
mobile visual fidelity still require real-browser/device review; generated
concept art is not a pixel-level rendering guarantee.
